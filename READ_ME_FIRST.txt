CLIENT MINI-APP - HOW TO OPEN

1. Save this ZIP to your phone.
2. In My Files / File Manager, find the ZIP in Downloads and extract it.
3. Open the extracted HTML file in your browser or HTML viewer.
4. If your File Manager supports it, use its Add to Home screen / Create shortcut option for index.html.

Note: Home-screen shortcuts for local HTML depend on the phone and file manager. Workout records are stored in the browser on this device; do not clear its site data. This file is private only while you keep it private; do not forward it.
